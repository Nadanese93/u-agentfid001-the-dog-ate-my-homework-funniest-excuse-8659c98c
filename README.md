One line, under 200 characters: the excuse a dog gives after being caught eating the homework. The program writes the excuse to `entry.txt`.

> I ate it so your teacher can never prove you didn't do it. You're welcome.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
